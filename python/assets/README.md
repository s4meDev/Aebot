# Identidade visual

Usei a logo Aegea do material de referência que recebi para a apresentação do projeto. O SVG original foi preservado, sem redesenhar a marca; o PNG é uma rasterização de 280 px de largura para o Tkinter.

Origem: `apresentacoes/AEBOT-2026-10-08/resumo/AEBOT_Apresentacao_Resumida.pptx`, recurso `ppt/media/image2.svg`.

A marca pertence à Aegea. Esta cópia é um recurso visual do protótipo interno, não uma declaração de homologação ou de autoria da marca. O aplicativo não baixa a imagem ao iniciar.
